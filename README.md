# Md Ayan Parwez — Engineering Portfolio (2026)

A complete React + Vite portfolio rebuild. Designed for software, backend, full-stack, AI and ML-oriented engineering roles.

## Run locally

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm run preview
```

Deploy on Vercel or Netlify as a Vite project (build: `npm run build`, output: `dist`).

## Included

- Responsive dark/light portfolio
- Filterable engineering project cards
- Experience timeline, skills, recruiter-friendly contact links
- Supplied résumé (`public/resume.pdf`) and certificate files (`public/certificates`)
- SEO metadata, semantic landmarks, reduced-motion support

## Before publishing

1. Check that the resume and certificate PDFs contain only information you want public. The provided résumé includes your phone number.
2. Verify each GitHub project link and replace missing demo/source links only with genuine URLs.
3. Verify reported metrics and claims with actual benchmark artifacts; they are currently labelled as résumé-reported.
4. Add real project screenshots, architectures, tests, deployment URLs and evaluation results.
5. Update contact email if the university email becomes inactive.
6. Confirm certificate titles, dates and authenticity before public release.

No fabricated AI chatbot, working contact backend, deployed demos, or unsupported performance claims are included. The contact button opens the user's email client.
